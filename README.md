# Jumping Rope

> Проект создан и собран с помощью [CodeSandbox](https://codesandbox.io/).

Небольшой экспериментальный проект на TypeScript — таймер интервальной тренировки со скакалкой. Исследование применения ООП в TypeScript: вместо готового фреймворка — собственная компактная архитектура на классах, интерфейсах и композиции.

## Что делает приложение

- Показывает текущее время.
- Отображает общий прогресс тренировки.
- Показывает текущий интервал: прыжки или отдых, оставшееся время и процент выполнения.
- Строит расписание из плана: серии прыжков разной длительности чередуются с отдыхом.

## Что здесь исследуется

- классы, интерфейсы и наследование;
- паттерн Singleton (`Application`, `OperationsManager`);
- паттерн Composite (`AbstractOperationComposite`);
- разделение модели, планировщика и UI-операций;
- работа с датами и временными интервалами без сторонних библиотек.

## Запуск

```bash
npm install
npm start
```

```bash
npm run build
```
